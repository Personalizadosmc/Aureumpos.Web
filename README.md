# Aureumpos.Web
Lanzamiento de la Web Aureumpos, Sistema de punto de venta diseñado para negocios de productos personalizados, que permite gestionar catálogos, procesar pedidos y generar cotizaciones de manera sencilla y eficiente.

Funcionalidades Principales
Para Clientes
Navegación Intuitiva del Catálogo

Exploración de productos organizados por categorías (tazas, termos, vasos, botellas personalizadas)
Búsqueda rápida de productos por nombre o precio
Visualización detallada de cada producto con imagen, nombre y precio
Gestión de Cuenta Personal

Registro de usuarios con información completa (nombre, apellido, direccion, teléfono)
Sistema de inicio de sesión seguro
Persistencia de datos entre sesiones
Carrito de Compras Personalizado

Carrito individual que mantiene los productos seleccionados incluso después de cerrar sesión
Ajuste de cantidades de productos de manera fácil
Visualización clara del subtotal por producto y total general
Opción de vaciar el carrito completamente
Generación de Cotizaciones

Creación de cotizaciones profesionales en formato PDF
Incluye información completa del cliente y detalle de productos
Descarga automática del documento para compartir o archivar
Identificador único para cada cotización generada
Proceso de Pago

Formulario de pago con validación de datos de tarjeta
Confirmación visual del monto total a pagar
Procesamiento simulado de transacciones
Para Administradores
Panel de Administración Completo

Acceso exclusivo mediante credenciales de administrador
Interfaz organizada por pestañas para mejor navegación
Gestión de Categorías

Creación de nuevas categorías de productos
Edición de categorías existentes (nombre e imagen)
Eliminación de categorías con advertencia de productos asociados
Visualización del número de productos por categoría
Gestión de Productos

Creación de nuevos productos con información detallada (nombre, precio, imagen, categoría)
Edición de productos existentes
Movimiento de productos entre categorías
Eliminación de productos individuales
Búsqueda de productos dentro del panel administrativo
Actualización automática de precios en todos los carritos de usuarios cuando se modifican productos
Características Generales
Información de Contacto Visible

Enlaces directos a WhatsApp para consultas inmediatas
Enlace a perfil de Instagram del negocio
Ubicación en mapa para facilitar visitas presenciales
Experiencia Visual Atractiva

Diseño responsive adaptable a diferentes dispositivos
Esquema de colores coherente y profesional
Animaciones sutiles que mejoran la interacción
Iconos descriptivos para mejor comprensión
Notificaciones al Usuario

Mensajes emergentes que confirman acciones exitosas
Alertas de error claras y descriptivas
Indicador visual del número de productos en el carrito
Persistencia de Datos

Toda la información se mantiene almacenada localmente
Los carritos de compra se preservan por usuario
Las categorías y productos creados permanecen disponibles
Casos de Uso
Para el Propietario del Negocio

Administrar el catálogo completo sin necesidad de conocimientos técnicos
Actualizar precios y productos de manera inmediata
Generar cotizaciones profesionales para enviar a clientes
Organizar productos por categorías para facilitar la navegación
Para el Cliente Final

Explorar productos disponibles antes de realizar una compra
Guardar productos de interés en el carrito para revisar después
Solicitar cotizaciones formales con un solo clic
Contactar directamente al negocio mediante WhatsApp
Completar el proceso de compra de manera guiada
Beneficios
Sin instalación requerida: Accesible desde cualquier navegador web
Gestión centralizada: Todos los productos y categorías en un solo lugar
Autonomía del cliente: Los usuarios pueden explorar y cotizar sin necesidad de asistencia
Profesionalismo: Cotizaciones en PDF con formato empresarial
Escalabilidad: Capacidad de agregar nuevas categorías y productos según crezca el negocio
Privacidad: Cada usuario tiene su propio carrito de compras independiente
